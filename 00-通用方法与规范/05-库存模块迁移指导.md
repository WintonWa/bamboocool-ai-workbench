## 4. 后端：`module.py` 的精确形状

外壳只读这一个文件。`_REQUIRED` 是 `id / label / api_version / pages / routes`，缺一个整个模块降级。

```python
from core import ctx as ctx_mod
from core.ruleset import Param
from . import compute, data

MODULE = {
    "id": "inventory",            # 必须等于目录名
    "label": "产品与库存",
    "api_version": 1,             # 必须是 1，不等就降级
    "prefix": "inv",              # 显式写，别靠默认
    "pages": [                    # 非空列表，每项必须有 id 和 label
        {"id": "inv-detail", "label": "单品盘点"},
        {"id": "inv-risk",   "label": "异常总览"},
        {"id": "inv-scope",  "label": "库存全览"},
    ],
    "routes": {                   # 非空字典：资源名 -> 可调用
        "meta":     handle_meta,
        "children": handle_children,
        "child":    handle_child,   # 路径段走 c.rest，见下
        "risk":     handle_risk,
        "scope":    handle_scope,
    },
    "params": PARAMS,             # list[Param]，可选
    "db": None,                   # 你读产品包，没有自己的库
    "invalidate": data.clear_caches,   # 热重载时清缓存，可选但强烈建议
}
```

**路由名不能带斜杠。** `_validate()` 会直接拒绝 `"child/<asin>"` 这种写法——竞品模块就是这么降级的。
路径段从 `Ctx.rest` 取：请求 `/api/inventory/child/B0GKFMB38P` 时，
`resource="child"`、`rest=("B0GKFMB38P",)`。

处理函数签名是 `handler(c: Ctx) -> 可 JSON 化对象`。`Ctx` 提供：

| 字段 / 方法 | 说明 |
| --- | --- |
| `c.module` / `c.resource` | 模块 id 与资源名 |
| `c.rest` | 剩余路径段元组 |
| `c.query` | `parse_qs` 结果，`{k: [v]}` |
| `c.params` | **已按你声明的上下限夹紧**的本模块参数，键不带前缀 |
| `c.fingerprint` | 参数指纹，缓存键用 |
| `c.as_of` | `2026-08-03` |
| `c.q(key, default)` / `c.q_all(key)` / `c.q_int(key, default)` | 取 query 便捷方法 |

参数声明改成：

```python
PARAMS = [
    Param("target_cover_days", "目标覆盖天数", default=60,
          kind="num", lo=7, hi=180, step=1, group="库存承接"),
    Param("depletion_method", "批次消耗", default="fifo",
          kind="enum", choices=[("fifo", "先进先出"), ("lifo", "后进先出")], group="批次"),
]
```

`kind="num"` 必须给 `lo/hi/step`（门禁 G6 查这个），越界值由外壳夹紧而不是透传。
参数名**不要自带前缀**（写 `target_cover_days` 不写 `inv.target_cover_days`），外壳自己拼。

## 5. 前端：精确的导出与 ctx 全集

`web/modules/inventory.js` 是 ES module，只导出这些：

```js
export const id = "inventory";
export const apiVersion = 1;
export const usesRail = true;            // 你有侧栏，设 true
export const filters = [                 // 声明式筛选，label 必须给（门禁 G18）
  { key: "q",      label: "搜子 ASIN" },
  { key: "risk",   label: "风险类型" },
  { key: "parent", label: "父体" },
];
export function pathFor({ pageId, objectId }) { /* 只返回模块名之后的尾段 */ }
export function parsePath(segments) { /* 收到的是模块名之后的段 */ }
export async function mount(slots, ctx) { /* slots = { rail, body } */ }
export async function render(ctx) { }
export function unmount() { }
```

**`mount` 的第一个参数是 `{ rail, body }` 两个 DOM 节点，不是单个容器。**
**`pathFor` 只返回尾段**，外壳自己加 `/inventory` 前缀——返回完整路径会得到 `/inventory/inventory/...`。

`ctx` 的全部内容，就这 20 项，一项不多：

| 类别 | 成员 |
| --- | --- |
| DOM | `$`、`$$`、`el(tag, attrs, children)` |
| 格式化 | `fmt.int` / `fmt.num` / `fmt.pct` / `fmt.money` / `fmt.days` / `fmt.date` / `fmt.dash` |
| 徽标 | `nature(v)`、`cond(v)` —— 只接受词表内的中文词，别的返回 `null` |
| 状态 | `state`（只有你自己那棵子树）、`shared`（只读）、`filters`（只读） |
| 当前位置 | `objectId`、`pageId`、`asOf`、`moduleId` |
| 改状态 | `setShared(patch)`、`setFilters(patch)`、`open(objectId, pageId)` |
| 取数 | `api(resource, extra)` —— resource 可带路径段，如 `api("child/" + encodeURIComponent(asin))`；当前筛选与参数自动带上，不用自己拼 query |
| 浮层抽屉 | `drawer.open(title, content, side)` / `drawer.close()`、`pop.show(anchor, content)` / `pop.close()` |
| 占位 | `placeholder(title, detail, kind)` |

你现在 `app.js` 里的 `$` / `el` / `pc` / 浮层实现**全部删掉换 ctx 的**。
两个模块各留一份浮层会互相抢"当前打开的是谁"。

## 6. 数据层

产品包路径外壳已经配好了，直接用，不要再写死绝对路径：

```python
from core import db, paths
con = db.connect(paths.PRODUCT_DB)      # 已指向 v0.3.0 那个 489MB 的 sqlite
```

`core/db.py` 提供 `connect / rows / one / scalar / table_names / attach / spine_children`，
语义和你现在 `lib/data.py` 里那三个一致（只读 URI + `Row` 工厂 + `query_only`），差别只在**显式传 `con`**。

**你的 `derived/chart_cache.sqlite` 是模块私有产物**，放 `modules/inventory/derived/`，
路径用 `Path(__file__).resolve().parent / "derived" / "chart_cache.sqlite"` 算，属于模块内部不违反集中原则。
如果你希望它也能被环境变量覆盖，**提出来让外壳在 `core/paths.py` 加一项**，
不要自己去改 `core/`——那是门禁和契约都禁止的。

`value_origin` 这类库内字段**不上屏**。上屏用两套固定词表：
数据性质 `真实 / 推导 / 模拟 / 混合`，数据状态 `正常 / 过期 / 缺失 / 待确认 / 失败 / 加载中 / 空结果`。
映射在读取边界做完，页面只拿中文词。参照 `modules/sample/data.py` 里的 `FIELD_LABELS` 白名单写法——
**用白名单不用黑名单**，黑名单会漏，数据包加一列就漏一次。

## 8. CSS 作用域

现在 `app.css` 用 `#id` 选择器和裸元素选择器（`section{}`、`table{}`、`th`、`td`），
这两样在合并后会**漏出去改别的模块的表格和卡片**。必改：

- 所有规则包进 `[data-module="inventory"] { … }`
- `#top` / `#side` / `#content` / `#params` 这类 id 选择器改成类
- `section{...}` / `table{...}` 改成带类名的选择器（如 `.inv-card` / `.inv-table`）
- **`--` 变量定义计数必须为 0**：只用 `web/tokens.css` 已有的令牌，需要新令牌就提出来加进 tokens.css
- 你现有的调色和圆角和 `tokens.css` 高度一致（当初就是同一套值），基本是改选择器不是改视觉

顺带两条你已经踩过、别在新版丢掉的：`.bars .fill` 必须 `display:block` + `position:absolute`
（行内 span 的宽高无效会塌成 0×0），以及 grid 轨道用 `minmax(0,1fr)` 不用 `1fr`。

## 10. 别人已经付过学费的六个坑

| # | 症状 | 原因与解法 |
| --- | --- | --- |
| 1 | 模块整个降级，`/api/inventory/*` 全 503 | 路由名带了斜杠（`"child/<asin>"`）。`_validate()` 直接拒。路径段走 `c.rest` |
| 2 | 参数怎么调都不生效 | `prefix` 没显式声明，外壳默认取 `mid[:3]`，实际前缀和你以为的不一样。显式写 `"inv"` |
| 3 | 深链 `/inventory/inv-detail` 打开却停在第一页 | `pathFor` 返回了完整路径，或返回了页面短别名。**直接返回 `pageId` 本身**。外壳的 `applyUrl()` 在模块 impl 加载前就解析 URL，此时拿不到你的 `parsePath`，会回落到按 `pages[].id` 匹配段名——所以路径里的段名必须就是 `pages[].id` |
| 4 | 某个参数名让门禁 G9 报泄漏 | 参数或字段名里含 `complete` / `partial` / `direct` / `derived` / `constructed` 等禁词子串。关键词把 `w_completeness` 改成了 `w_evidence` |
| 5 | 一列数据在每行重复 50 遍 | 恒定值列是噪音。在概要里说一次，只给和主体不同的行打标 |
| 6 | `[hidden]` 的元素照样吃掉点击 | `[hidden]{display:none}` 属 UA 来源，作者样式写了 `display` 就盖掉它。外壳已加全局 `!important`，但你判断显隐时要查 `getComputedStyle().display` + `getBoundingClientRect()` + `elementFromPoint()` 三者，别只查 `.hidden` |

环境两条：`/usr/bin/python3` 是 **3.9.6**，`dataclass(slots=True)`、`match` 都不能用；
改了 `modules/` 下的 `.py` 靠 mtime 热重载，改了 `core/` 一律重启，改 `web/` 刷新即生效。

3. **`--sans` 两套不一致，这是个待决口径。**
