# 广告 Demo 数据构建范围

- 页面一：按广告类型、标签和对象层级筛选，查看同口径表现、横向比较和规则异常；不输出调整建议。
- 页面二：以单一子 ASIN 为决策对象，串联产品目标、库存、关键词、竞品、历史动作、任务、结构对照、诊断、建议、运营决定和 D+3/D+7 反馈。
- 产品范围：5 个父 ASIN、完整 521 个子 ASIN；首个纵向切片使用 `B088WF1PRW`。
- 广告范围：真实报表共 54 个广告组名称键（SP 40、SB 5、SD 9）；名称键不冒充 Amazon 稳定 ID。
- 时间范围：Amazon 事实为 `2026-07-01` 至 `2026-07-31`；SP 采用 7 天归因，SB/SD 采用 14 天归因，不跨归因混加。
- 数据承载：SQLite 为标准层，前端 JSON 与验收 JSON 均由同一脚本导出。
- 数据边界：每条记录区分 `direct / derived / supplemented / scenario_added / blocked`，并保留来源文件、行选择条件和计算口径。
- 构建顺序：先完成页面一与页面二各一个纵向切片；验收通过后再批量生成完整范围。
