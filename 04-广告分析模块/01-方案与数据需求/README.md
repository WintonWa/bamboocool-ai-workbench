### 几个反复出错的口径，先说清

**归因窗口按广告类型分**：SB 14 天 / SD 14 天 / SP 7 天。同一个 ACoS 在两个窗口下不是一个数，
页面上并排的两个盒子（`14 天归因 · SB/SD` 与 `7 天归因 · SP`）就是这个原因。

**粒度是广告组，不是 Campaign 也不是投放对象。** 855 个投放对象汇总到 54 个广告组来判断。

**「异常」分四类，判据完全不同**：绝对阈值 / 数据状态 / 相对同组对象偏离 / 相对自身历史。
一个对象可以同时命中多类。数据状态那类（如「日粒度样本不足」）**不是效率问题**，
是证据不够，不能当成投放做得差。

**目的标签是数据包烤好的，不是 Agent 判的。** 54 个对象里 11 个「无法识别」。
`loop-a1` 那个 Agent 有代码有路由但一次没成功跑过。

**这个模块的 as_of 没有在数据包里声明**，全靠 `paths.AS_OF = 2026-08-03` 兜着。
