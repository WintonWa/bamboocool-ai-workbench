# 子 ASIN 数据与 Agent 实施计划

## 目标

在不修改 v0.2.2 的前提下生成 v0.3.0 数据包，并把现有父 ASIN 固定公式 Demo 升级为子 ASIN 逐日需求预测和库存决策 Agent。

## 实施顺序

1. 新建可重复执行的 Python 数据生成器，复制 v0.2.2 SQLite 后增加 B 层历史、计划、预测、库存和 Demo 路由表。
2. 为全部 342 个子 ASIN生成 730 天完整历史和 90 天未来计划；五个黄金样本使用人工场景，其余样本使用固定种子和父级约束。
3. 实现历史质量分类、需求还原、三候选模型回测、驱动因素修正、P10/P50/P90 和三场景库存投影。
4. 输出 v0.3.0 SQLite、JSON、Schema Catalog、血缘、生成配置、质量、父子调平和黄金场景报告。
5. 重构 Node 数据仓库接口，新增九个只读业务工具、子 ASIN 场景 Skill、系统 Prompt 和稳定执行事件映射。
6. 更新 API 与前端：子 ASIN选择、黄金场景标签、90 天问题、九步执行轨迹和完整结论。
7. 增加数据构建测试、业务工具测试、API/事件测试和真实 Pi 冒烟测试。
8. 运行浏览器桌面/窄屏验收，更新 README 并提交精确范围内的改动。

## 完成门槛

- v0.3.0 全部质量检查通过；
- v0.2.2 未被修改；
- 5 个黄金样本故事可验证；
- Node 自动化测试全部通过；
- 本机真实 Pi 能完整调用九个工具并输出预测与库存建议；
- 页面无控制台错误且窄屏无横向溢出。
