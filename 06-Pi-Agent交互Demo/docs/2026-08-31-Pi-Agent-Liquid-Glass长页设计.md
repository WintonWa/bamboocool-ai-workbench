# Bamboocool Pi Agent Liquid Glass 长页设计

日期：2026-08-31  
状态：已批准，直接进入实现  
目标目录：`06-Pi-Agent交互Demo/`

## 1. 目标

把现有 Pi Agent 对话首页重构为一个移动优先的长篇产品页，视觉上复现参考图的浅青背景、玻璃主视觉、单列编号卡片和底部深色 CTA，同时保留现有子 ASIN 预测 Agent 的真实交互能力。

参考图片只用于结构、节奏和质感判断。图片中的 Codex、iOS、WebGL 示例文案不属于项目事实，不直接进入成品。

## 2. 已批准方向

采用“轻量长页复现”方向：

- 单列阅读流，手机端为主，桌面端阅读宽度约 760px；
- 浅青到暖白的环境背景，配少量低对比光晕；
- Hero 保持短标题、简短说明和一个可交互玻璃按钮；
- 内容以 9 个编号段落讲清 Pi Agent 的业务链路；
- 卡片使用 Organic Soft-Tech 的深绿、薄荷、暖白和低透明度环境阴影；
- 页面后半段嵌入真实 Agent 交互区；
- 结尾使用深绿色 CTA，引导返回并启动 Agent。

## 3. 页面结构

### 3.1 顶部信息条

左侧显示 Bamboocool / Product Brief，右侧显示 Pi Agent / Live Demo。信息条不做复杂导航，保持参考图的轻量文档感。

### 3.2 Hero

标题：让 Pi Agent 真正进入运营工作流。

说明：强调它不是预录动画，而是由受限工具、真实数据和流式事件共同组成的可解释业务链路。

主视觉是一块半透明玻璃舞台，中央放置“Ask Pi Agent”胶囊按钮。按钮支持：

- 指针移动时高光跟随；
- 轻微色散边缘；
- 柔和浮起与按压反馈；
- 点击滚动到 Live Agent Demo；
- 键盘聚焦和低动态模式。

玻璃效果以 CSS 渐变、`backdrop-filter`、多层阴影和少量指针变量实现。视觉降级时仍保持清晰按钮与足够对比度。

### 3.3 核心说明条

Hero 下方放置深绿色短说明条，直接说明页面的核心判断：

“真正的 Agent 体验，不是把答案做成动画，而是让每一步工具调用、数据来源和结果边界都可见。”

### 3.4 九个编号内容段落

1. **角色与目标**：说明这是面向子 ASIN 销量、库存和补货判断的固定场景 Demo。
2. **先确认业务对象**：展示子 ASIN 路由、父体关系、生命周期和演示画像。
3. **审计逐日历史**：说明 Agent 会检查 730 天日粒度历史、缺失与异常。
4. **还原真实需求**：说明缺货、促销和数据失真需要先处理再预测。
5. **评估经营驱动**：说明价格、广告、活动和生命周期信号的用途与边界。
6. **形成 90 天预测**：说明逐日预测、P10/P50/P90 和模型派生标记。
7. **推演库存三场景**：说明基准、压力、改善三种库存承接结果。
8. **给出补货建议**：说明风险日期、建议数量和不可用于真实采购承诺的边界。
9. **让执行过程可见**：引出 Live Agent Demo，强调九步调用来自真实流式事件，不展示模型原始思维链。

段落不会全部做成同尺寸白卡。穿插深色重点卡、开放式清单、步骤轨迹和玻璃表面，避免重复卡片墙。

### 3.5 Live Agent Demo

保留现有功能和后端契约：

- 子 ASIN 选择；
- 产品元数据；
- 推荐问题；
- 消息输入；
- 发送、停止、重新运行、清空；
- 九步执行轨迹；
- 流式答案；
- 服务连接状态；
- 错误、取消和警告状态。

桌面端交互区可以在阅读列内略微扩宽；手机端保持单列。原有 DOM ID 与 API 请求格式尽量保持不变，减少逻辑回归风险。

### 3.6 结尾 CTA

使用深绿色圆角玻璃块，文案强调“看见 Agent 如何把判断做出来”。按钮滚动回 Live Agent Demo，并在可用时聚焦输入框。

## 4. 视觉系统

- 背景：`#eef5f1`、`#f7faf8`、`#fbf9f8` 的浅色层次；
- 主色：Organic Soft-Tech 深绿 `#172d21`；
- 辅色：`#2d4336`、`#b3cdbb`、`#dcece0`；
- 标题：Plus Jakarta Sans，并使用中文系统字体回退；
- 正文：Be Vietnam Pro，并使用中文系统字体回退；
- 大容器圆角 28–32px，内容块 18–24px，按钮全胶囊；
- 阴影保持低透明度、绿色倾向和较大模糊；
- 正文与背景满足可读性要求，交互焦点明确可见。

## 5. 响应式与动效

- 390px：参考图式单列长页，左右留白 16–20px；
- 768px 以上：阅读列约 720–760px，部分清单可切为双列；
- 1200px 以上：仅增加环境留白和装饰光晕，不把页面扩成密集仪表盘；
- 支持 `prefers-reduced-motion`；
- 玻璃按钮与卡片只做轻量位移、色散和高光变化，不做持续大幅动画；
- 触屏设备不依赖 hover 才能理解或操作页面。

## 6. 数据与内容边界

- 继续使用 `/api/health`、`/api/children` 和 `/api/agent/run`；
- 不改九个工具的调用顺序与事件协议；
- 不编造客户数据；
- 明确区分原始、演示构造和模型派生结果；
- 不展示模型原始思维链、SQL、文件路径或原始工具 JSON；
- 不把参考图中的 iOS/WebGL 技术说明写成 Bamboocool 的已实现能力。
