# 关键词分析模块 · 源表勘查

> 只有一个脚本。**一次性探查，不是产线代码。**

## `probe_kw_asin_overlap.py`

回答一个问题：**客户给的关键词数据里的 ASIN，和产品脊椎那 342 个子体重合多少。**

读 `/Users/linsen/BAM/数据源/AI广告对接数据-总20260803/10.关键词`，只读，不写。

结论已经落进构建决策：本模块只覆盖脊椎里的 **30 个重点子体**，不是全部 342 个。
所以关键词页面上「覆盖率」这类指标的分母是 30 不是 342 —— 这一条容易看错。

## 怎么跑

```bash
cd /Users/linsen/BAM/07-关键词分析模块/00-源表勘查
/usr/bin/python3 probe_kw_asin_overlap.py
```

Python 必须 `/usr/bin/python3`（3.9.6）。脚本硬编码了客户原始目录的绝对路径，换机器要改。

## 为什么这个模块只有一个探查脚本

关键词的源表勘查主要不在这里，在 `../02-数据构建/` 里 —— 那 13 个脚本里
`lib_kwsrc.py` 承担了源表读取与规格化，勘查和构建是一起做的。
详见 `../02-数据构建/README.md`。
