# Organic Soft-Tech 使用说明

这是 Bamboocool 工作台的共享设计规范资料包，存放在项目资料库中，供产品设计、页面扩展、前端实现和视觉验收长期复用。

## 建议读取顺序

1. `DESIGN.md`：Google Stitch 导出的原始设计系统，定义品牌、颜色、字体、间距、圆角和组件原则。
2. `tokens.css`：可复制到前端代码中的命名设计令牌。
3. `components.md`：针对当前运营工作台的信息密度和组件落地规则。
4. `references.md`：Stitch 项目、节点、截图、HTML 和视觉验收证据索引。

## 文件夹说明

- `Stitch源文件/`：未经改写的设计系统、四个参考页面截图和 HTML。
- `视觉验收/`：当前 Organic Soft-Tech Demo 与 Stitch 参考的对照截图及 QA 记录。
- `operator-avatar.jpg`：Stitch 参考页面使用的运营人员头像素材。

## 规范优先级

发生冲突时按以下顺序处理：

1. 用户当前明确提出的要求。
2. `DESIGN.md` 的品牌、颜色、字体、节奏和 Organic 视觉原则。
3. `components.md` 的工作台密度适配。
4. 已确认的页面结构、PRD 和业务决策。
5. 现有前端实现。

不要静默混入 BambooCool Internal 或其他风格。需要尝试其他设计系统时，应建立单独版本或副本。
