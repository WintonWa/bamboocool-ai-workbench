# Bamboocool 产品与库存页架构与决策记录

## 1. 页面定位和范围

产品与库存页位于“产品与库存判断 → 关键词和竞品分析佐证 → 广告决策 → 人工执行 → 3/7 天回溯”闭环的起点。

这个页面的核心不是把所有产品数据做成一张大报表，而是让运营快速找到产品、看懂当前状态，并判断接下来需不需要处理。第一阶段先形成判断和建议，不直接替运营执行。

## 2. 总览页和产品与库存页分别做什么

- 总览页负责汇总经营结果、重要异常和待处理建议，让运营先知道“今天整体怎么样、哪里需要看”。
- 产品与库存页负责下钻到具体产品，回答“是哪个子 ASIN 出了什么问题、为什么、接下来该关注什么”。
- 总览页只承接结论和入口，产品与库存页保留支撑判断所需的产品明细。

## 3. 判断单元：以子 ASIN 为最小颗粒度

产品判断不能停留在父体层面。即使同一父体下，不同颜色、规格或子体的销售、广告和库存状态也可能完全不同，因此：

- 每个子 ASIN 是最小判断单元；
- 父体主要用于归属、聚合查看和快速定位；
- 主列表一行对应一个子 ASIN；
- 销量预测、库存风险、补货判断和仓储费风险都落到子 ASIN。

## 4. 产品定位驱动规则，并依赖产品跟踪表

不同产品定位和阶段不能共用同一套判断标准。后续由产品跟踪表提供产品定位、产品阶段等信息，工作台据此调用不同的判断规则。

目前已经确定“产品定位和阶段会影响规则”，但具体分类、字段和对应标准尚未确定，不能先行假设。产品跟踪表也因此是本页落地的重要数据依赖。

## 5. 页面信息架构和快速查询

### 顶部固定快速筛选

第一版先固定以下入口：

- ASIN / 产品名称；
- 产品定位；
- 库存风险；
- 销售状态；
- 时间范围。

### 主列表

主列表默认按“更需要处理、风险更高”优先排列，而不是简单按产品名称或销量排列。每个子 ASIN 只展示结论级信息：

- 销售表现结论；
- 库存覆盖和风险结论；
- 临近 BD 对预测的影响；
- 当前综合结论。

详细数据不全部平铺，运营需要时再打开单个子 ASIN 的详情。

### Agent 查询

Agent 不做成独立聊天页面，而是嵌入产品查询流程。运营可以针对当前选中的产品或筛选结果继续提问，Agent 先给出结论，再引导用户查看对应的销量、预测、库存或仓储费支撑明细。

## 6. 统一销量预测：BD 是输入，不是独立功能

页面统一提供未来 90 天的预计销量和库存消耗。

BD 不单独做一个预测模块。后台下载到的 BD 计划日期，与稳定的历史销量数据、产品定位和阶段一起进入销量预测。这样可以避免“日常销量预测”和“BD 预测”形成两套相互冲突的结果。

目前只确定预测框架和 90 天范围，具体预测方法、BD 影响方式、历史数据窗口和更新频率仍需后续确认。

## 7. 库存、补货和仓储费判断链路

库存判断承接销量预测结果，并结合：

- 当前可售库存；
- 在途库存；
- 已计划但尚未收货的库存；
- 预留及不可售库存；
- 不同库龄的库存。

在数据和规则具备后，页面需要进一步给出：

- 预计可覆盖时间；
- 预计冗余库存；
- 预计缺货日期；
- 建议补货时间和数量；
- 库龄及仓储费风险。

补货判断还依赖采购及运输交期、安全库存规则；仓储费风险依赖收费节点、费率和库龄口径。以上标准目前均不能自行设定。

## 8. 后续需要补齐的能力和数据

- 包含 BD 计划输入的 90 天销量预测能力；
- 各类库存数据的稳定抓取和口径对应；
- 基于交期与安全库存规则的补货计算；
- 库龄及仓储费计算；
- 从产品跟踪表读取产品定位、阶段并配置对应规则；
- 稳定、连续、可追溯的销售历史数据；
- 支持 Agent 引用筛选结果和单品明细的查询能力。

## 9. 已确认与待客户确认

### 已确认

- 页面定位是快速找产品、看结论和做判断，不是全数据报表；
- 子 ASIN 是最小判断单元；
- 产品定位和阶段驱动差异化规则，数据来自产品跟踪表；
- 顶部采用固定快速筛选，主列表按待处理和风险优先；
- 主列表只放结论级信息，详情按需打开；
- Agent 嵌入查询流程；
- 统一提供 90 天销量和库存消耗预测；
- BD 计划日期作为销量预测输入，不独立成一个功能；
- 库存判断向覆盖、缺货、补货和仓储费风险延伸。

### 待客户确认

- 产品跟踪表的字段、产品定位和阶段分类；
- 不同定位、阶段对应的销售和库存判断规则；
- 库存风险与销售状态的口径；
- 风险优先排序和提示标准；
- 销量预测方法、BD 影响规则、历史数据范围及更新频率；
- 可售、在途、未收货、预留、不可售和库龄库存的具体口径；
- 交期、安全库存及补货时间和数量的计算规则；
- 仓储费收费节点、费率、库龄口径和风险标准；
- Agent 常见提问、详情层级及可引用的数据范围。
