# 工作台真实视图地图

这份地图按用户实际能看到的状态盘点，而不是只按 `module.py` 中的 `pages` 数量盘点。

| 模块 | 基础路由/登记页 | 代码中的二级状态与跳转 | 本批视觉稿 |
|---|---|---|---|
| 总览 | `/overview` | 模块卡与结论跳到库存、关键词、竞品、广告 | 运营总览 |
| 产品与库存 | `/inventory/inv-detail/<asin>` | 左侧对象栏切换子 ASIN；销量与需求图点击某日展开当日解释；盘点结论可打开全局任务面板 | 单品盘点、单日联动详情、任务面板 |
| 产品与库存 | `/inventory/inv-risk` | 风险构成、严重度、承接能力、置信度 | 异常总览 |
| 产品与库存 | `/inventory/inv-scope` | 当前筛选范围汇总 | 库存全览 |
| 关键词 | `/keyword` | 变化表和优先事项可跳到子 ASIN 关键词盘点 | 动态与机会总览 |
| 面料预投 | `/preinvest/pre-plan` | 342 个子 ASIN 全列；页头 Buffer 改动联动系统建议与运营最终量；行内可改“我要投”并导出 | 预投表 |
| 面料预投 | `/preinvest/pre-detail/<asin>` | 左栏选择子 ASIN；“看依据”进入；复用库存逐日图并圈出预投窗口，继续展示需求预测 Agent 的五项判断 | 单品依据 |
| 关键词 | `/keyword/kw-market` | 市场词库表；点击关键词进入独立的 `kw-term` 页面并保留对象 id | 市场关键词库 |
| 关键词 | `/keyword/kw-child` | 30 个重点子体按真实锚点数排序；点击行进入该子体的独立关键词盘点页 | 重点子体清单 |
| 关键词 | `/keyword/kw-term/<term>` | `renderTerm`：词身份、月/周双频趋势、两来源对照、头部 ASIN、产品关系；可继续跳子 ASIN | 单词深研、单一关键词分析独立页 |
| 关键词 | `/keyword/kw-asin/<asin>` | `renderChild`：身份与结论、需求词组覆盖、自然/广告位变化、证据组、历次盘点 | 子 ASIN 关键词盘点、独立页签版 |
| 竞品 | `/competitor` | 表格行和左侧快捷关注位跳单一竞品 | 竞品威胁总览 |
| 竞品 | `/competitor/cmp-rival/<family>` | 共同时间线、判断、市场与价格、关键词证据、事实/模拟/假设、分析记录 | 单一竞品分析 |
| 竞品 | 详情页内抽屉 | “产品族与报价关系”打开右侧抽屉；共同时间线点击某日打开说明浮层 | 产品族与报价关系抽屉 |
| 广告 | `/ads/ads-catalog` | 左侧组合筛选；勾选多行显示横向对比；点击广告对象打开详情抽屉 | 广告分类与数据查看、广告对象详情抽屉 |
| 广告 | `/ads/ads-decision/<asin>` | 子 ASIN 选择；依据区；未运行、运行中、已完成三种 Agent 阶段状态；标准决策单展开“动作 / 原因 / 预期结果” | 单一子 ASIN 广告决策、Agent 决策完成态、标准决策单视觉优化 |
| Agent 配置 | `/agentcfg` | 点击 Agent 卡片后 URL 进入 `/agentcfg/<agent-id>` | Agent 与门槛、单个 Agent 门槛详情 |
| Agent 配置 | `/agentcfg/runs` | 点击一次运行打开右侧完整字段抽屉 | Agent 输出记录、单次运行详情抽屉 |
| 全局外壳 | 任意业务页 | 右侧“任务”把手打开运行步骤面板 | Agent 任务进度面板 |

`sample`/`接入范例` 只用于验证模块接入契约，没有客户业务判断，因此不作为正式视觉探索对象。
