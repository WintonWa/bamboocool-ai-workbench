# 逐张预览与可借鉴点

## 总览

### 01 运营总览

可借鉴：用“先看什么”建立首屏优先级，再用不对称决策矩阵承接四个模块，不把总览做成等权 KPI 卡片墙。

![运营总览](images/01-运营总览.png)

## 产品与库存

### 02 单品盘点

可借鉴：把销量预测与库存消耗放在连续阅读路径中；左侧对象栏、上方商品身份、中央关系图各自承担一层任务。

![单品盘点](images/02-产品库存-单品盘点.png)

### 03 异常总览

可借鉴：风险类型排序条 + 严重度/承接能力矩阵 + 高风险对象表，分别回答“哪类严重、为什么严重、先看谁”。

![异常总览](images/03-产品库存-异常总览.png)

### 04 库存全览

可借鉴：库存流带把总量和构成放在同一张图里；库龄段、覆盖天数和费用继续解释时间与成本。

![库存全览](images/04-产品库存-库存全览.png)

### 15 单日联动详情

可借鉴：点击日期后把“当天事实—预估对照—调整原因”直接展开在图下，不脱离时间上下文。

![单日联动详情](images/15-产品库存-单日联动详情.png)

## 面料预投

### 23 预投表

可借鉴：把“预测 → Buffer → 系统建议 → 运营最终”收成一条计算账带，下方直接进入 342 个子 ASIN 的批量审批表；输入与结果的因果关系比四张 KPI 卡更清楚。

![面料预投表](images/23-面料预投-预投表.png)

### 24 单品依据

可借鉴：顶部只保留一条数量推导链；主图复用库存逐日预测并用蓝色窗口圈出这次预投真正覆盖的销售月，Agent 五项判断紧接在图后解释预测。

![面料预投单品依据](images/24-面料预投-单品依据.png)

## 关键词分析

### 05 动态与机会总览

可借鉴：上涨/下滑的发散条与覆盖增减流带共享时间，右侧五问速览用于快速读数，底部清单用于下一步分流。

![关键词动态与机会总览](images/05-关键词-动态机会总览.png)

### 06 市场关键词库

可借鉴：机会散点图同时表达需供比、购买率、搜索量和词角色；下方表格保留精确比较和深研入口。

![市场关键词库](images/06-关键词-市场词库.png)

### 14 单词深研

可借鉴：把月频和周频拆成两张同宽小倍图，避免错误折算；两来源对照、头部 ASIN 与产品关系围绕单词对象展开。

![单词深研](images/14-关键词-单词深研.png)

### 25 重点子体清单

可借鉴：这是一张真正的“先找谁”列表。关系词数用微型 bullet，真实锚点占比使用同尺度条，产品目标和库存承接保留文字状态，不制造综合分数。

![重点子体清单](images/25-关键词-重点子体清单.png)

### 26 单一关键词分析 · 独立页签版

可借鉴：五页页签和左侧关键词对象栏让深研页不再藏在词库行点击里；月频、周频、来源差异、头部 ASIN 与产品关系在同一屏形成稳定阅读顺序。

![单一关键词分析独立页](images/26-关键词-单一关键词分析-独立页.png)

### 07 子 ASIN 关键词盘点

可借鉴：“词角色 × 排名/覆盖状态”矩阵是这页最有辨识度的核心图；自然位与广告位采用同轴双轨。

![子 ASIN 关键词盘点](images/07-关键词-子ASIN盘点.png)

### 27 单一子 ASIN 盘点 · 独立页签版

可借鉴：把身份与五条经营结论连成一个判读面，再用需求词组覆盖条、自然/广告位双轨与证据清单分别回答“缺哪儿、怎么变、下一步去哪儿”。

![单一子 ASIN 盘点独立页](images/27-关键词-单一子ASIN盘点-独立页.png)

## 竞品分析

### 08 竞品威胁总览

可借鉴：在比较表单元格内嵌趋势线和单位价差 bullet chart，不造综合威胁分数也能快速排序判断。

![竞品威胁总览](images/08-竞品-威胁总览.png)

### 09 单一竞品分析

可借鉴：价格、活动、销量/排名、流量、关键词和自有事件共用一条时间轴，右侧将事实、模拟、假设、因果未知分开。

![单一竞品分析](images/09-竞品-单一竞品分析.png)

### 16 产品族与报价关系抽屉

可借鉴：详情页不离场，用右侧抽屉展开子体报价，再用件单价区间图处理不同装数不可直接比的问题。

![产品族与报价关系抽屉](images/16-竞品-产品族报价抽屉.png)

## 广告分析

### 10 广告分类与数据查看

可借鉴：7 天/14 天归因分栏、异常规则排序、对象宽表和勾选对比槽构成清晰的“筛选—定位—比较”链路。

![广告分类与数据查看](images/10-广告-分类数据查看.png)

### 17 广告对象详情抽屉

可借鉴：总览表负责找对象，抽屉用逐日花费/销售额/ACoS 与异常证据解释对象，职责不重复。

![广告对象详情抽屉](images/17-广告-对象详情抽屉.png)

### 11 单一子 ASIN 广告决策

可借鉴：三列输入证据在上，五段经营决策链在中，当前结构在下，顺序明确表达“依据先于判断”。

![单一子 ASIN 广告决策](images/11-广告-单一子ASIN决策.png)

### 18 Agent 决策完成态

可借鉴：用连续编号和证据编号呈现 Agent 的四阶段结果；“接受/修改/暂不处理”清楚表明仍需运营确认。

![广告 Agent 决策完成态](images/18-广告-Agent决策完成态.png)

### 22 标准决策单视觉优化

可借鉴：将固定 Agent 契约压成“动作 / 原因 / 预期结果”的标准决策单，并把“当前值 → 目标值”设为唯一强焦点；完整提示词单独保存在 [22-广告-标准决策单视觉优化-prompt.md](22-广告-标准决策单视觉优化-prompt.md)。

![广告标准决策单视觉优化](images/22-广告-标准决策单视觉优化.png)

## Agent 配置与运行

### 12 Agent 与门槛

可借鉴：把 Agent 状态做成可扫描表，并在右侧检查器展示职责边界与门槛，信息密度比卡片墙更稳。

![Agent 与门槛](images/12-Agent配置-与门槛.png)

### 19 单个 Agent 门槛详情

可借鉴：左侧职责边界、右侧配置方案与参数对照；方案值与默认值并排比，已修改项一眼可见。

![单个 Agent 门槛详情](images/19-Agent配置-单Agent门槛详情.png)

### 13 Agent 输出记录

可借鉴：按天分组的运行时间线配状态矩阵和耗时排行，既能查单次记录，也能发现整条链路的不稳定性。

![Agent 输出记录](images/13-Agent配置-输出记录.png)

### 20 单次运行详情抽屉

可借鉴：时间线不离场，抽屉展示原始时间戳、数据口径和分步耗时，突出审计而不是对话。

![单次运行详情抽屉](images/20-Agent配置-单次运行详情抽屉.png)

## 全局外壳

### 21 Agent 任务进度面板

可借鉴：业务页保持白色实面，只有右侧任务浮层使用轻玻璃；每一步显示真实来源、状态和耗时。

![Agent 任务进度面板](images/21-全局-Agent任务进度面板.png)
