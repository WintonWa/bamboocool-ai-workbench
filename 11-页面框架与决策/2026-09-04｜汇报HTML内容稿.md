# Bamboocool AI 运营工作台

数据截止：2026-08-03（美东时间）｜站点：美国站 Amazon.com｜对象：342 个在售子 ASIN / 57 个配色组

---

## 一、项目背景

Bamboocool 美国站日常运营涉及 342 个在售子体，运营动作覆盖库存补货、面料预投、关键词布局、竞品监控和广告投放五个环节。

目前这些判断全部依赖人工经验和 Excel：预投靠 3/7/15/30 天销量拉平均再凭感觉调，库存靠逐个翻表，广告和关键词靠人盯。每个人的经验不一样，偏差也不一样。

偏差落到钱上：投多了面料变成资金占用，投少了断货丢销量，中间隔着两个半月，改不回来。

---

## 二、核心思路

**判断交给 AI Agent，承接交给工作台。**

| | 谁做 | 做什么 |
|---|---|---|
| AI Agent | 那些没有公式、只能靠经验判断的事 |
| 工作台 | 算术、换算、排序、出表、留痕 |

AI 只出「建议 + 原因 + 预期结果」，运营确认后才生效。系统不会自动下单，不会自动改广告。

---

## 三、整体架构

工作台共 **5 个业务模块 + 1 个配置模块 + 1 个总览**，合计 **18 个页面**。

| 模块 | 页数 | 回答的问题 |
|---|---|---|
| 产品与库存 | 3 | 补货、清货、断货，先看谁 |
| 面料预投 | 3 | 这一轮该投多少面料 |
| 关键词分析 | 5 | 哪些词该动、该守还是该抢 |
| 竞品分析 | 2 | 竞品在做什么、影响到我们哪里 |
| 广告分析 | 2 | 广告钱花得值不值、该怎么调 |
| Agent 配置与运行 | 2 | AI 判断的边界和门槛，可改、可查 |
| 运营总览 | 1 | 今天先看什么 |

## 四、产品与库存（3 页）

管的是已经变成货的那部分——补货、清货、断货。

### 4.1 单品盘点

一个子体当下该不该动、动什么，一屏看完。

- 商品身份、生命周期、风险结论
- 销量与需求：左边历史实销，右边 AI 预测（带上下界），标出活动和到货
- 库存承接：可售余额、在途到货、安全线、预计断货日
- 点击任意一天可展开当天的详细解释

![单品盘点](images/02-产品库存-单品盘点.png)

**AI 能力**：需求预测 Agent 判断真实需求（缺货扭曲、活动影响、生命周期阶段），盘点结论 Agent 判断当下最该做什么。

### 4.2 异常总览

几秒内定位最高风险的对象。

- 四个核心数字：有风险 / 风险条数 / 多风险叠加 / 无风险
- 五类风险按影响件数排序（库存不足、库龄、超量备货、可用性异常、仓储费）
- 严重度 × 承接能力矩阵
- 高风险对象清单

![异常总览](images/03-产品库存-异常总览.png)

**AI 能力**：库存总体分析 Agent 从各对象结论中挑出重点、排序。

### 4.3 库存全览

整个筛选范围的库存健康度。

- 总量：可售 / FBA 合计 / 总库存 / 近 30 天销量
- 库存构成：可售、受限、在途、超龄
- 库龄分段与未来跨龄量
- 估算仓储费

![库存全览](images/04-产品库存-库存全览.png)

## 五、面料预投（3 页）

管的是钱出去之前——这一轮面料投多少。

判断对象是配色组（款号 × 组合），共 57 个。时间口径 M+2：8 月做的预投对应 10 月销量。考核标准：下单数 ÷ 预投数 ≥ 70%。

### 5.1 预投考核

上一轮投准了没有，用真实历史数据回答。

- 达成率 vs 70% 考核线
- 逐月预投走势
- 未达考核线的配色组清单

> 待补图：预投考核页

### 5.2 预投计划

替代运营现在填 Excel 的动作。

- 57 行分两堆：需要复核的（标出原因）和按建议走的
- 每行可直接修改投入量，折吨与合计实时变化
- 底部导出预投表交生产端

> 待补图：预投计划页

### 5.3 配色组依据

某一行的建议值该接受还是该改。

- 决策条：系统建议 → 我最终投 → 折面料
- 逐日柱状图：历史实销 + AI 预估，销售月那一段高亮标出
- 三样反驳证据：去年同期、上一轮达成率、下月活动

> 待补图：配色组依据页

**AI 能力**：复用需求预测 Agent 的逐子体预估，按配色组聚合后给出建议值。

### 8.1 广告分类与数据查看

- 7 天 / 14 天归因分栏
- 异常规则命中排序

![广告分类与数据查看](images/10-广告-分类数据查看.png)

### 8.2 单一子 ASIN 广告决策

- 三列判断依据：经营约束、广告表现、关键词与竞品证据

**AI 能力**：广告异常与决策 Agent 判断该调价、该扩量还是样本不够；广告目的标签 Agent 从命名和投放行为判断每个广告对象在干什么。

## 十一、预期效果

| 环节 | 现在 | 接入后 |
|---|---|---|
| 预投准确度 | 运营凭经验填 Excel，各人偏差不同 | AI 基于历史 + 活动 + 生命周期给建议，运营只复核异常行 |
| 库存风险识别 | 人工逐个翻表 | 系统自动标出高风险对象并排优先级 |
| 关键词布局 | 人工盯排名变化 | 系统识别机会与风险词，给出优先级和下一步 |
| 竞品监控 | 不定期手动查看 | 每周自动比对，变化自动标出 |
| 广告调整 | 人工看报表做判断 | AI 出诊断和建议，运营确认后执行 |

所有 AI 建议均需运营确认才生效，判断边界和门槛透明可调，每次运行有完整记录可追溯。
