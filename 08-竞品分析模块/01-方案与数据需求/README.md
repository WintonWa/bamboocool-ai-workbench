### 几个反复出错的口径，先说清

**判断对象是竞品产品族（父 ASIN），不是单个竞品 ASIN。** 这一条决定总览那张比较表的行是什么。

**价差按件单价比，不按标价比。** `pack_resolved = 0` 的（装量没解析出来的）要排除，
否则 3 件装和 1 件装直接比价是错的。

**观察窗口 `2026-02-05 ~ 2026-08-03`，但流量结构那张表是月粒度。**
`fact_competitor_traffic_mix` 的 `period_start` 取月初，含 window_from 那个月的起点是
`2026-02-01`——比窗口起点早 4 天。**这是对的**，不是 Agent 编日期：日粒度对齐窗口，
月粒度按所属统计区间起点判。契约 G4 当初没给月粒度留口径，报过一次假红。

**七个阈值随请求传，不是写死在包里。** 改了阈值 `threshold_fingerprint` 就变，
相关 run 会退成待确认。

**同期变化 ≠ 因果。** `causal_ready` 默认 0。Agent 只记同期变化，不判因果。

**id 由写入端盖章，不由 Agent 输出**：`report_id` / `handoff_id` / `report.item_seq` 等 11 个字段。
单对象重跑时 Agent 拿不到全局排位，必然算错。
